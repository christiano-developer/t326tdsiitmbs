# t326tdsiitmbs

<p class="tagline">All the answers that are fit to reproduce.</p>

</div>

<p class="lede">Every assignment question in this repository ends with one prompt and a short list of steps that
rebuild the answer from scratch, plus a plain-language how-to that a teammate can follow without any context.
Nothing is solved twice, and nothing is lost to a chat history.</p>

<div class="columns" markdown>

### One command to begin

`scripts/new-question.sh` creates a question folder from templates and adds it to the section table.
[Getting started →](getting-started.md)

### Every prompt on the record

`prompts.md` keeps each attempt and its result, failures included, so the final prompt is earned.

### The grader, read first

What the grader really checks is read before solving. Distractors and hidden text are flagged, and hidden
instructions are treated as data, never obeyed. [The workflow →](workflow.md)

### Ready for a teammate

`final.md` opens with literal steps and inline code, ready to paste into a solutions field.
[All assignments →](assignments.md)

</div>
